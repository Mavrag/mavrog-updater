# Mavrog Updater

A small desktop app that keeps the **MavrogBattleCry** World of Warcraft addon up to date.

## Download

Grab the latest `MavrogUpdater.exe` from the [Releases](https://github.com/Mavrag/mavrog-updater/releases/latest) page.

## Usage

1. Run `MavrogUpdater.exe`.
2. It will auto-detect your WoW Retail AddOns folder. If not found, you'll be prompted to select it.
3. Click **Check for Updates** to see if a new addon version is available.
4. Click **Install Update** to download and install it.

The app also checks for updates to itself and will prompt you when a new version is available.
